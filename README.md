# Apparao Devarasetty

Data engineer in Charlotte, NC. Five-plus years of building pipelines and the tooling around them — Python, SQL, PySpark, Kafka, Spark, Airflow, mostly on AWS and Azure. Day job: Charter Communications.

## What I've built here

**[nl-to-sql-assistant](https://github.com/sivaking177/nl-to-sql-assistant)** — Ask questions about NYC taxi data in plain English. A language model writes the SQL, a guardrail layer decides what is allowed to run, and DuckDB answers. It ships with a fixed evaluation set, so changes get graded instead of guessed at.

**[streaming-anomaly-detection](https://github.com/sivaking177/streaming-anomaly-detection)** — Watches the live Wikimedia edit stream, groups it into one-minute windows, and flags the minutes that don't look like the recent past. Kafka and Spark Structured Streaming, with a local simulation so the whole thing can be tested without a cluster.

Both repos include their validation notes — what was actually run, and what the numbers came out as.
